## Installation Process

- ``git clone git@bitbucket.org:retinasoft/ajaxerp.git``
- ``cd ajaxerp``
- ``composer install``
- ``cp .env.example .env``
- Set database credentials in **.env** file
- ``php artisan migrate --seed``

Installation Complete
